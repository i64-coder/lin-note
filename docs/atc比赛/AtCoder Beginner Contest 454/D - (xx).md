# D - (xx)

## 题目描述

给定一个仅由字符 `(`、`x`、`)` 组成的字符串 $A$。

你可以对 $A$ 任意多次、以任意顺序执行以下两种操作：

- 选择 $A$ 中的一个子串 `(xx)`，将其替换为 `xx`。
- 选择 $A$ 中的一个子串 `xx`，将其替换为 `(xx)`。

另外给定一个同样由 `(`、`x`、`)` 组成的字符串 $B$。判断是否可以通过上述操作将 $A$ 变成 $B$。

你需要处理 $T$ 组测试数据。

> **什么是子串**  
> 字符串 $S$ 的子串是指从 $S$ 中连续取出的一部分字符构成的字符串。

## 输入格式

输入从标准输入按以下格式给出：

$T$  
$A_1$  
$B_1$  
$A_2$  
$B_2$  
$\cdots$  
$A_T$  
$B_T$  

其中第 $i$ 组测试数据由字符串 $A_i$ 和 $B_i$ 组成。

## 输出格式

输出 $T$ 行。第 $i$ 行应为第 $i$ 组测试数据的答案。  
如果能通过操作将 $A_i$ 变为 $B_i$，则输出 `Yes`；否则输出 `No`。

## 样例

### 样例1.输入

```
6
(xx)x
x(xx)
(x)x
(xx)
)x()x(
)x()x(
x
(x)
(((((xx)))))x
x((((((((((xx))))))))))
((xx)xx)xx
(x((xx))x)(xx)
```

### 样例1.输出

```
Yes
No
Yes
No
Yes
Yes
```

## 提示

例如，在第一组测试数据中，可以通过如下步骤将 $A$ 转换为 $B$：

- 将 $A = \texttt{(xx)x}$ 中第 $1$ 到第 $4$ 个字符组成的子串 `(xx)` 替换为 `xx`，得到 `xxx`。
- 将 `xxx` 中第 $2$ 到第 $3$ 个字符组成的子串 `xx` 替换为 `(xx)`，得到 `x(xx)`。

---

**约束条件：**

- $1 \leq T \leq 3 \times 10^5$
- 所有字符串 $A$ 和 $B$ 的长度均在 $1$ 到 $2 \times 10^6$ 之间（含），且仅包含字符 `(`、`x`、`)`
- 所有测试数据中 $\lvert A \rvert + \lvert B \rvert$ 的总和不超过 $2 \times 10^6$（$\lvert A \rvert$ 表示字符串 $A$ 的长度）

## 思路

操作的对称性非常明显：两种操作是**互逆**的。这意味着，如果某个字符串 $S$ 可以通过操作变成 $T$，那么 $T$ 也可以通过逆操作变回 $S$。因此，我们可以考虑定义一种**“规范形式”**（或“最简形式”），使得所有能互相转化的字符串都约化到同一个规范形式。

什么样的规范形式自然呢？注意到操作只涉及 `(xx)` 和 `xx` 之间的替换，而括号 `(` 和 `)` 仅出现在 `(xx)` 中。如果我们将所有形如 `(xx)` 的部分都“化简”为 `xx`，那么最终字符串中就不再含有任何可以继续化简的 `(xx)` 结构了。而且，如果两个字符串能通过操作互相转化，那么它们化简后得到的字符串必然相同；反之，如果化简结果相同，那么我们可以先通过化简操作将 $A$ 变为规范形式，再通过逆操作将规范形式变为 $B$，从而完成转化。

因此，问题转化为：设计一种确定性的化简算法，将字符串中的每个 `(xx)` 都消去。

最直接的思路是：从左到右扫描字符串，用一个栈（或字符串模拟）维护当前已经处理的部分。当我们读入一个新字符时：

- 如果是 `(` 或 `x`，直接压入栈。
- 如果是 `)`，检查栈顶的三个字符是否恰好构成 `(xx`。如果是，说明我们恰好遇到一个完整的 `(xx)` 子串，此时应该将它化简为 `xx`。

为什么这样是正确的？因为每次消去一个 `(xx)` 后，可能会暴露出新的可以消去的模式（例如 `((xx))` 变成 `(xx)` 后， `xx` 可以再次与前面和后面的字符形成新的 `(xx)`）。而我们的算法“即时消去”正好可以处理这种连锁反应：当 `)` 触发消去后，栈顶变成了若干字符，此时如果后面再次遇到 `)`，可能再次触发消去。

    #include "bits/stdc++.h"
    using namespace std;
    using ll = long long;
    #define endl '\n'
    #define read(x) scanf ("%lld", &x)

    string a, b;
    string get(string s) 
    {
        string res;
        for (auto c : s) 
        {
            if (c == '(' || c == 'x') res += c;
            else
            {
                if (res.size() >= 3 && res.substr(res.size() - 3) == "(xx") res.erase(res.size() - 3, 1);
                else res += c;
            }
        }
        return res;
    }
    void solve()
    {
        cin >> a >> b;
        if (get(a) == get(b)) cout << "Yes" << endl;
        else cout << "No" << endl;
    }

    int main()
    {
        ll t; cin >> t; while (t --) solve();
        return 0;
    }
