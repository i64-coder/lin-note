# C - Straw Millionaire

## 题目描述

有 $N$ 种物品，编号为物品 $1$ 到物品 $N$。最初，高桥只有物品 $1$。

他有 $M$ 位朋友。如果他将物品 $A_i$ 给第 $i$ 位朋友（$1 \leq i \leq M$），他将获得物品 $B_i$。

求他能获得多少种不同的物品（包括初始拥有的物品 $1$）。

## 输入格式

$N\ M$  
$A_1\ B_1$  
$A_2\ B_2$  
$\cdots$  
$A_M\ B_M$  

## 输出格式

输出答案。

## 样例

### 样例1.输入

```
5 5
1 2
2 3
3 4
2 4
5 2
```

### 样例1.输出

```
4
```

例如，高桥可以通过以下方式获得物品 $4$：  

- 将物品 $1$ 给第 $1$ 位朋友，获得物品 $2$。  
- 将物品 $2$ 给第 $4$ 位朋友，获得物品 $4$。  

他可以获得 $4$ 种物品：物品 $1, 2, 3, 4$。因此，输出 $4$。

### 样例2.输入

```
3 2
2 1
3 2
```

### 样例2.输出

```
1
```

他只能获得 $1$ 种物品：物品 $1$。

### 样例3.输入

```
7 8
2 6
2 5
3 6
1 6
1 2
5 6
2 3
3 7
```

### 样例3.输出

```
6
```

## 思路

## 思路

本质上这是一个图上的可达性问题。  
假如对于第 $i$ 位朋友来说，如果送出 $A_i$，那么高桥就可以获得 $B_i$，这样有一个隐藏的前提：高桥得具备物品 $A_i$ 才能送出；

高桥一开始只有物品 $1$，可能有多位朋友需要物品 $1$，并且他们会送出相应的物品给高桥，高桥可以一直这样下去——只要他拥有某个物品 $x$，就能触发所有以 $x$ 为输入的交换规则，从而获得新的物品。而新获得的物品又可能作为其他交换的输入，继续触发更多交换。

这实际上构成了一个**有向图的传播过程**：
- 每种物品是一个节点（共 $N$ 个节点，编号 $1$ 到 $N$）；
- 每条交换规则 $(A_i, B_i)$ 是一条从 $A_i$ 指向 $B_i$ 的有向边；
- 初始时，节点 $1$ 被“激活”（即高桥拥有该物品）；
- 若一个节点被激活，则其所有出边指向的节点也会被激活；
- 激活过程持续进行，直到没有新节点可被激活为止。

因此，问题等价于：**从节点 $1$ 出发，在有向图中通过任意长度的路径能够到达的节点总数（包括节点 $1$ 自身）是多少？**

由于图中可能存在环（如 $2 \to 3$、$3 \to 2$），必须使用访问标记（visited 数组）防止重复处理。
我们可以采用广度优先搜索（BFS）或深度优先搜索（DFS）模拟这一传播过程：

1. 构建邻接表：对每个物品 $u$，存储所有可通过一次交换直接获得的物品 $v$（即所有满足 $A_i = u$ 的 $B_i$）；
2. 初始化一个队列（BFS）或递归栈（DFS），并将物品 $1$ 加入；
3. 维护一个布尔数组 `has` 或 `visited`，记录当前已拥有的物品；
4. 不断取出当前拥有的物品，遍历其所有出边，将未拥有的目标物品加入队列并标记为已拥有；
5. 最终统计 `visited` 中为真的元素个数，即为答案。

该算法的时间复杂度为 $O(N + M)$，空间复杂度也为 $O(N + M)$，完全适用于题目约束。

例如在样例 2 中：
输入为
```
3 2
2 1
3 2
```
邻接表为 $2 \to 1$、$3 \to 2$，但高桥初始只有物品 $1$，而没有任何边以 $1$ 为起点，因此无法触发任何交换，最终只能拥有物品 $1$，输出 $1$。

而在样例 3 中，从 $1$ 出发可逐步激活 $2, 6, 5, 3, 7$，共 $6$ 种物品，故输出 $6$。
