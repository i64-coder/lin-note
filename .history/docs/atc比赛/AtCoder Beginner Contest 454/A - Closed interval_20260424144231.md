# A - Closed interval

## 题目描述

给定两个整数 $L$ 和 $R$。

求在区间 $[L, R]$（包含端点）中有多少个整数。

## 输入格式

输入从标准输入按以下格式给出：

```
L R
```

## 输出格式

输出答案。

## 样例

### 样例1.输入

```
3 5
```

### 样例1.输出

```
3
```

在区间 $[3, 5]$ 中的整数是 $3, 4, 5$，共三个整数。因此输出 `3`。

### 样例2.输入

```
1 7
```

### 样例2.输出

```
7
```

### 样例3.输入

```
14 79
```

### 样例3.输出

```
66
```

## 思路

```cpp linenums="1"
#include <bits/stdc++.h>
using namespace std;
int main() {
    int l, r;
    cin >> l >> r;
    cout << r - l + 1 << endl;
    return 0;
}
```
