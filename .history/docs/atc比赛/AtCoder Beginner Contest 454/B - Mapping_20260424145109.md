# B - Mapping  

## 题目描述  

有 $N$ 个人，编号为 $1$ 到 $N$。  
有 $M$ 种衣服，编号为 $1$ 到 $M$。第 $i$ 个人穿的衣服类型为 $F_i$。  

请回答以下两个问题（输出 Yes 或 No）：  

- 问题 1：这 $N$ 个人是否每个人都穿着**不同种类**的衣服？  
- 问题 2：对于每一种 $1$ 到 $M$ 的衣服类型，是否**至少有一个人**穿着该类型的衣服？  

## 输入格式  

输入从标准输入按如下格式给出：  

$N \  M$  
$F_1\ F_2\ \dots\ F_N$  

## 输出格式  

输出两行。第 $i$ 行输出 `Yes` 如果问题 $i$ 的答案是肯定的，否则输出 `No`。  

## 样例  

### 样例1.输入  

```
3 4
1 2 4
```  

### 样例1.输出  

```
Yes
No
```  

> 所有人都穿着不同类型的衣服，因此问题 1 的答案是 Yes。  
> 没有人穿衣服类型 3，因此问题 2 的答案是 No。  

### 样例2.输入  

```
4 2
1 2 1 2
```  

### 样例2.输出  

```
No
Yes
```  

### 样例3.输入  

```
4 4
1 3 2 1
```  

### 样例3.输出  

```
No
No
```  

### 样例4.输入  

```
5 5
1 3 4 2 5
```  

### 样例4.输出  

```
Yes
Yes
```
