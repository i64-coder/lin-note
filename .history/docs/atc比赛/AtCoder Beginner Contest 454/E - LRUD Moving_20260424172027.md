# E - LRUD Moving

## 题目描述

给定正整数 $N, A, B$。保证 $A$ 和 $B$ 均在 $1$ 到 $N$（含）之间。

有一个 $N \times N$ 的网格。从上往下第 $i$ 行、从左往右第 $j$ 列的格子记为 $(i,j)$。初始时，棋子位于 $(1,1)$。

你需要进行 $N^2 - 2$ 次移动，每次将棋子移动到相邻的格子（上、下、左、右），使得：

- 最终棋子到达 $(N,N)$；
- **除了格子 $(A,B)$ 外，所有格子都恰好被访问一次**；
- **不能重复访问任何格子**（包括起点 $(1,1)$ 和终点 $(N,N)$ 在中间也不能再次访问）。

请你判断是否存在满足条件的移动序列。如果存在，输出任意一个合法方案。

本题包含 $T$ 组测试数据，请依次求解每组数据。

## 输入格式

$T$  
$N\ A\ B$  
$\cdots$（共 $T$ 行）

## 输出格式

对每组测试数据，如果无解，输出 `No`。

否则按如下格式输出：

Yes  
$S_1\ S_2\ \cdots\ S_{N^2 - 2}$

其中，设第 $k$ 次移动前棋子位于 $(i,j)$，则：

- 若移动到 $(i,j-1)$，则 $S_k = \texttt{L}$
- 若移动到 $(i,j+1)$，则 $S_k = \texttt{R}$
- 若移动到 $(i-1,j)$，则 $S_k = \texttt{U}$
- 若移动到 $(i+1,j)$，则 $S_k = \texttt{D}$

若有多种合法方案，输出任意一种即可。

## 样例

### 样例1.输入

```
3
2 1 2
3 2 2
4 3 2
```

### 样例1.输出

```
Yes
DR
No
Yes
RRRDLLLDDRRURD
```

## 提示

对于第一个测试用例：  

初始棋子在 $(1,1)$，进行如下两次移动：  

- 向下移动，棋子到达 $(2,1)$。  
- 向右移动，棋子到达 $(2,2)$。  

该移动序列满足所有条件。  

---

保证 $(A,B) \ne (1,1)$ 且 $(A,B) \ne (N,N)$。  

所有输入均为整数。  

对于所有测试数据，满足：  
- $1 \le T \le 5000$  
- $2 \le N \le 10^3$  
- $1 \le A, B \le N$  
- 所有测试数据中 $N^2$ 的总和不超过 $10^6$

## 思路

### 特殊性质

对于**二维矩形网格图**（行数 \(m \ge 2\)，列数 \(n \ge 2\)），从固定起点出发，要构造一条经过**所有格子恰好一次**的路径(哈密顿路径)，有如下结论：

- 当总格子数 \(m \times n\) 为**奇数**时，终点必须与起点同色，且**所有与起点同色格子均可作为终点**。
- 当总格子数 \(m \times n\) 为**偶数**时，终点必须与起点异色，且**所有与起点异色格子均可作为终点**。

这一结论在网格图理论中是已知的。唯一的例外是退化的一维网格（如 \(1 \times n\) 或 \(n \times 1\)），此时哈密顿路径只能沿直线移动，终点只能是两个端点之一。

### 回归原题

回到原题，题目要求构造一条哈密顿路径，且路径必须避开一个特定的格子 $(A,B)$，因此需要走：$N^2 - 1$ 个格子；  
我们令：每走一步就改变一次颜色（黑变白，白变黑），规定起点是黑色；  

如果 $N$ 是偶数，那么 $N^2 - 1$ 是奇数
