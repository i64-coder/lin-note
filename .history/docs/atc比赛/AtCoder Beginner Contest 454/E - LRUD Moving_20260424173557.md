# E - LRUD Moving

## 题目描述

给定正整数 $N, A, B$。保证 $A$ 和 $B$ 均在 $1$ 到 $N$（含）之间。

有一个 $N \times N$ 的网格。从上往下第 $i$ 行、从左往右第 $j$ 列的格子记为 $(i,j)$。初始时，棋子位于 $(1,1)$。

你需要进行 $N^2 - 2$ 次移动，每次将棋子移动到相邻的格子（上、下、左、右），使得：

- 最终棋子到达 $(N,N)$；
- **除了格子 $(A,B)$ 外，所有格子都恰好被访问一次**；
- **不能重复访问任何格子**（包括起点 $(1,1)$ 和终点 $(N,N)$ 在中间也不能再次访问）。

请你判断是否存在满足条件的移动序列。如果存在，输出任意一个合法方案。

本题包含 $T$ 组测试数据，请依次求解每组数据。

## 输入格式

$T$  
$N\ A\ B$  
$\cdots$（共 $T$ 行）

## 输出格式

对每组测试数据，如果无解，输出 `No`。

否则按如下格式输出：

Yes  
$S_1\ S_2\ \cdots\ S_{N^2 - 2}$

其中，设第 $k$ 次移动前棋子位于 $(i,j)$，则：

- 若移动到 $(i,j-1)$，则 $S_k = \texttt{L}$
- 若移动到 $(i,j+1)$，则 $S_k = \texttt{R}$
- 若移动到 $(i-1,j)$，则 $S_k = \texttt{U}$
- 若移动到 $(i+1,j)$，则 $S_k = \texttt{D}$

若有多种合法方案，输出任意一种即可。

## 样例

### 样例1.输入

```
3
2 1 2
3 2 2
4 3 2
```

### 样例1.输出

```
Yes
DR
No
Yes
RRRDLLLDDRRURD
```

## 提示

对于第一个测试用例：  

初始棋子在 $(1,1)$，进行如下两次移动：  

- 向下移动，棋子到达 $(2,1)$。  
- 向右移动，棋子到达 $(2,2)$。  

该移动序列满足所有条件。  

---

保证 $(A,B) \ne (1,1)$ 且 $(A,B) \ne (N,N)$。  

所有输入均为整数。  

对于所有测试数据，满足：  
- $1 \le T \le 5000$  
- $2 \le N \le 10^3$  
- $1 \le A, B \le N$  
- 所有测试数据中 $N^2$ 的总和不超过 $10^6$

## 思路

对于一般的 \(n \times m\) 矩形网格图（\(n, m \ge 1\)），存在哈密顿路径（经过所有格子恰好一次）的充要条件为：

**起点与终点的颜色必须满足路径步数的奇偶性要求。**
具体地，按 \(i+j\) 的奇偶性染色（设 \((1,1)\) 为黑色），总格子数为 \(S = n \times m\)，路径步数为 \(S-1\)。
- 若 \(S\) 为奇数，则步数 \(S-1\) 为偶数，故终点必须与起点同色。
- 若 \(S\) 为偶数，则步数 \(S-1\) 为奇数，故终点必须与起点异色。

该条件也是充分的 —— 对于任意矩形网格（\(n, m \ge 2\) 或退化的一维情况 \(n=1\) 或 \(m=1\)），只要起点和终点满足上述颜色匹配，就一定存在一条哈密顿路径。
（对于一维网格，即路径图，哈密顿路径唯一且自动满足该条件。）

**特别说明：**
- 矩形网格图总存在哈密顿路径，但起终点的选择受限于颜色。例如 \(3\times 3\) 网格（\(S=9\) 奇数），只能连接两个同色格子；而 \(2\times 3\) 网格（\(S=6\) 偶数），只能连接两个异色格子。
- 当 \(n=m=1\) 时，只有一个格子，起点即为终点，哈密顿路径退化为零步，自动满足条件。
