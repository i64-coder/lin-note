# C - Straw Millionaire

## 题目描述

有 $N$ 种物品，编号为物品 $1$ 到物品 $N$。最初，高桥只有物品 $1$。

他有 $M$ 位朋友。如果他将物品 $A_i$ 给第 $i$ 位朋友（$1 \leq i \leq M$），他将获得物品 $B_i$。

求他能获得多少种不同的物品（包括初始拥有的物品 $1$）。

## 输入格式

$N\ M$  
$A_1\ B_1$  
$A_2\ B_2$  
$\cdots$  
$A_M\ B_M$  

## 输出格式

输出答案。

## 样例

### 样例1.输入

```
5 5
1 2
2 3
3 4
2 4
5 2
```

### 样例1.输出

```
4
```

例如，高桥可以通过以下方式获得物品 $4$：  

- 将物品 $1$ 给第 $1$ 位朋友，获得物品 $2$。  
- 将物品 $2$ 给第 $4$ 位朋友，获得物品 $4$。  

他可以获得 $4$ 种物品：物品 $1, 2, 3, 4$。因此，输出 $4$。

### 样例2.输入

```
3 2
2 1
3 2
```

### 样例2.输出

```
1
```

他只能获得 $1$ 种物品：物品 $1$。

### 样例3.输入

```
7 8
2 6
2 5
3 6
1 6
1 2
5 6
2 3
3 7
```

### 样例3.输出

```
6
```
