# C - Straw Millionaire

## 题目描述

有 $N$ 种物品，编号为 $1$ 到 $N$。初始时，高桥只拥有物品 $1$。

他有 $M$ 个朋友。如果他将物品 $A_i$ 给第 $i$ 个朋友（$1 \leq i \leq M$），他将会收到物品 $B_i$。

求他最终能够获得的物品种类数（包括物品 $1$）。

## 输入格式

输入从标准输入按以下格式给出：

```
N M
A_1 B_1
A_2 B_2
⋮
A_M B_M
```

## 输出格式

输出答案。

## 样例

### 样例1.输入

```
5 5
1 2
2 3
3 4
2 4
5 2
```

### 样例1.输出

```
4
```

例如，高桥可以通过如下操作获得物品 $4$：

- 将物品 $1$ 给第一个朋友，获得物品 $2$。
- 将物品 $2$ 给第四个朋友，获得物品 $4$。

他可以获得物品 $1,2,3,4$，共 $4$ 种。因此输出 $4$。

### 样例2.输入

```
3 2
2 1
3 2
```

### 样例2.输出

```
1
```

他只能获得物品 $1$，共 $1$ 种。

### 样例3.输入

```
7 8
2 6
2 5
3 6
1 6
1 2
5 6
2 3
3 7
```

### 样例3.输出

```
6
```
