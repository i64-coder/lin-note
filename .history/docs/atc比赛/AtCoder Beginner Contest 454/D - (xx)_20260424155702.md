# D - (xx)

## 题目描述

给定一个仅由字符 `(`、`x`、`)` 组成的字符串 $A$。

你可以对 $A$ 任意多次、以任意顺序执行以下两种操作：

- 选择 $A$ 中的一个子串 `(xx)`，将其替换为 `xx`。
- 选择 $A$ 中的一个子串 `xx`，将其替换为 `(xx)`。

另外给定一个同样由 `(`、`x`、`)` 组成的字符串 $B$。判断是否可以通过上述操作将 $A$ 变成 $B$。

你需要处理 $T$ 组测试数据。

> **什么是子串**  
> 字符串 $S$ 的子串是指从 $S$ 中连续取出的一部分字符构成的字符串。

## 输入格式

输入从标准输入按以下格式给出：

$T$  
$A_1$  
$B_1$  
$A_2$  
$B_2$  
$\cdots$  
$A_T$  
$B_T$  

其中第 $i$ 组测试数据由字符串 $A_i$ 和 $B_i$ 组成。

## 输出格式

输出 $T$ 行。第 $i$ 行应为第 $i$ 组测试数据的答案。  
如果能通过操作将 $A_i$ 变为 $B_i$，则输出 `Yes`；否则输出 `No`。

## 样例

### 样例1.输入

```
6
(xx)x
x(xx)
(x)x
(xx)
)x()x(
)x()x(
x
(x)
(((((xx)))))x
x((((((((((xx))))))))))
((xx)xx)xx
(x((xx))x)(xx)
```

### 样例1.输出

```
Yes
No
Yes
No
Yes
Yes
```

## 提示

例如，在第一组测试数据中，可以通过如下步骤将 $A$ 转换为 $B$：

- 将 $A = \texttt{(xx)x}$ 中第 $1$ 到第 $4$ 个字符组成的子串 `(xx)` 替换为 `xx`，得到 `xxx`。
- 将 `xxx` 中第 $2$ 到第 $3$ 个字符组成的子串 `xx` 替换为 `(xx)`，得到 `x(xx)`。

---

**约束条件：**

- $1 \leq T \leq 3 \times 10^5$
- 所有字符串 $A$ 和 $B$ 的长度均在 $1$ 到 $2 \times 10^6$ 之间（含），且仅包含字符 `(`、`x`、`)`
- 所有测试数据中 $\lvert A \rvert + \lvert B \rvert$ 的总和不超过 $2 \times 10^6$（$\lvert A \rvert$ 表示字符串 $A$ 的长度）

## 思路

    ```cpp linenums="1"
    #include "bits/stdc++.h"
    using namespace std;
    using ll = long long;
    #define endl '\n'
    #define read(x) scanf ("%lld", &x)

    string a, b;
    string get(string s) 
    {
        string ans;
        vector<char> stk;
        string tmp;
        for (auto c : s)
        {
            if (c == 'x')
            {
                if (stk.empty() || tmp.size() == 2) 
                {
                    ans.append(stk.begin(), stk.end()); stk.clear(); ans += tmp; tmp.clear();
                    ans += c; 
                }
                else tmp += c;
            }
            else if (c == '(') 
            {
                if (tmp.size())
                {
                    ans.append(stk.begin(), stk.end()); stk.clear(); ans += tmp; tmp.clear();
                }
                stk.push_back(c);
            }
            else if (c == ')')
            {
                if (tmp.size() == 2 && stk.size()) stk.pop_back();
                else 
                {
                    ans.append(stk.begin(), stk.end()); stk.clear(); ans += tmp; tmp.clear();
                    ans += c;
                }
            }
        }
        ans.append(stk.begin(), stk.end()); stk.clear(); ans += tmp; tmp.clear();

        return ans;
    }
    void solve()
    {
        cin >> a >> b;
        if (get(a) == get(b)) cout << "Yes" << endl;
        else cout << "No" << endl;
    }

    int main()
    {
        ll t; cin >> t; while (t --) solve();
        return 0;
    }
    ```
