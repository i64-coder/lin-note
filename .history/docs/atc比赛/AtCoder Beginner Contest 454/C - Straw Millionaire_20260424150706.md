# C - Straw Millionaire

## 题目描述

有 $N$ 种物品，编号为物品 $1$ 到物品 $N$。最初，高桥只有物品 $1$。

他有 $M$ 位朋友。如果他将物品 $A_i$ 给第 $i$ 位朋友（$1 \leq i \leq M$），他将获得物品 $B_i$。

求他能获得多少种不同的物品（包括初始拥有的物品 $1$）。

## 输入格式

$N\ M$  
$A_1\ B_1$  
$A_2\ B_2$  
$\cdots$  
$A_M\ B_M$  

## 输出格式

输出答案。

## 样例

### 样例1.输入

```
5 5
1 2
2 3
3 4
2 4
5 2
```

### 样例1.输出

```
4
```

例如，高桥可以通过以下方式获得物品 $4$：  

- 将物品 $1$ 给第 $1$ 位朋友，获得物品 $2$。  
- 将物品 $2$ 给第 $4$ 位朋友，获得物品 $4$。  

他可以获得 $4$ 种物品：物品 $1, 2, 3, 4$。因此，输出 $4$。

### 样例2.输入

```
3 2
2 1
3 2
```

### 样例2.输出

```
1
```

他只能获得 $1$ 种物品：物品 $1$。

### 样例3.输入

```
7 8
2 6
2 5
3 6
1 6
1 2
5 6
2 3
3 7
```

### 样例3.输出

```
6
```

## 思路

本题本质上是一个**有向图的可达性问题**。

将每种物品视为图中的一个节点（共 $N$ 个），每条交换规则 $(A_i, B_i)$ 视为一条从 $A_i$ 指向 $B_i$ 的有向边。高桥初始拥有物品 $1$，即从节点 $1$ 出发，能通过有向边到达的所有节点（包括自身）即为他最终能获得的物品集合。

由于交换具有依赖性——只有拥有 $A_i$ 才能获得 $B_i$——这等价于从节点 $1$ 开始进行图的遍历，不断激活新节点，直到无法继续为止。图中可能存在环，因此需用 `visited` 数组避免重复访问。

具体做法：
1. 构建邻接表，记录每个物品能直接换得的物品；
2. 从物品 $1$ 开始，使用 BFS 或 DFS 遍历所有可达节点；
3. 统计被访问过的节点数量，即为答案。

时间复杂度为 $O(N + M)$，空间复杂度为 $O(N + M)$，高效可行。

例如样例 2 中，虽然存在边 $2 \to 1$ 和 $3 \to 2$，但因无法从 $1$ 出发到达 $2$ 或 $3$，故只能获得物品 $1$；而样例 3 中从 $1$ 可逐步激活 $2, 6, 5, 3, 7$，共 $6$ 种物品。
