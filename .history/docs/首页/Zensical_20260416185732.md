### 2. 列对齐（左 / 居中 / 右）

| 左对齐       | 居中对齐      | 右对齐        |
| :----------- | :-----------: | ------------: |
| 内容 A       | 内容 B        | 内容 C        |
| `code`       | **加粗**      | ==高亮==      |

### 3. 配置要求

启用 Markdown 表格支持（通常默认开启）：

**zensical.toml 或 mkdocs.yml**
```toml
[project.markdown_extensions.tables]
```

~~~toml
[project.markdown_extensions.tables]
~~~

---

### 4. （可选）启用排序功能

添加外部 JS 实现点击列排序：

**zensical.toml 或 mkdocs.yml**
```toml
[project]
extra_javascript = [
    "https://unpkg.com/tablesort@5.3.0/dist/tablesort.min.js",
    "javascripts/tablesort.js"
]
```

> 💡 需自行创建 `docs/javascripts/tablesort.js` 初始化脚本。
> 排序支持数字、日期、文件大小等类型（详见 tablesort 文档）。

~~~toml
[project]
extra_javascript = [
    "https://unpkg.com/tablesort@5.3.0/dist/tablesort.min.js",
~~~
