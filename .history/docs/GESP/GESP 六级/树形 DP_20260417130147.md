# 树形 DP

**树形DP（Tree DP）** 是动态规划的一种特殊形式，专门用于解决**树结构**上的最优化问题。它利用树的递归性质和无环特性，在树上进行状态转移。

## 核心思想

1. **以树为载体**：问题的输入是一个树结构（有根树或无根树）
2. **状态定义**：通常定义 `dp[u][...]` 表示**以节点u为根的子树**在某种约束条件下的最优解
3. **自底向上计算**：通过后序遍历，先计算子节点的状态，再推导父节点的状态
4. **无后效性**：由于树的无环性质，子树之间的状态相互独立

## 基本步骤

### 1. 状态设计
```python
# 常见状态定义方式
dp[u] = 以u为根的子树的某种最优值
dp[u][0/1] = u选/不选时子树的最优值
dp[u][k] = 子树中选择k个节点的最优值
```

### 2. 状态转移
- **合并子树信息**：将各个子树的DP值合并到当前节点
- **考虑父子关系**：根据题目约束处理父节点和子节点的选择关系

### 3. 遍历方式
- **DFS后序遍历**：最常用，确保子节点先于父节点计算
- **换根DP**：对于无根树问题，可能需要两次DFS

## 经典例题

### 1. 没有上司的舞会（最大独立集）
- **状态**：`dp[u][0/1]` 表示u不参加/参加时子树的最大快乐值
- **转移**：
  - `dp[u][1] = val[u] + Σdp[v][0]` （u参加，子节点都不能参加）
  - `dp[u][0] = Σmax(dp[v][0], dp[v][1])` （u不参加，子节点可选）

### 2. 树的最小点覆盖
- **状态**：`dp[u][0/1]` 表示u不选/选时覆盖子树所有边的最小点数
- **转移**：
  - `dp[u][1] = 1 + Σmin(dp[v][0], dp[v][1])`
  - `dp[u][0] = Σdp[v][1]` （u不选，则所有子节点必须选）

## 实现框架

```python
def dfs(u, parent):
    # 初始化当前节点状态
    initialize_dp(u)
  
    # 遍历所有子节点
    for v in adj[u]:
        if v != parent:
            dfs(v, u)           # 递归处理子树
            update_dp(u, v)     # 用子节点v的信息更新u的状态
  
    # 可能还需要后处理
    post_process(u)
```

## 关键特点

- **时间复杂度**：通常是 O(n) 或 O(n×状态数)
- **空间复杂度**：O(n) 存储DP数组 + O(h) 递归栈（h为树高）
- **适用场景**：树上的选择、覆盖、路径、连通性等最优化问题

树形DP的本质就是**将复杂的树上问题分解为子树问题，通过动态规划的方式高效求解**。
