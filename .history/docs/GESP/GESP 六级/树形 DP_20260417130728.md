# 树形 DP

**树形 DP** 是动态规划的一种特殊形式，专门用于解决**树结构**上的最优化问题。它利用树的递归性质和无环特性，在树上进行状态转移。

## 核心思想

1. **以树为载体**：问题的输入是一个树结构（有根树或无根树）
2. **状态定义**：通常定义 `dp[u][...]` 表示**以节点u为根的子树**在某种约束条件下的最优解
3. **自底向上计算**：通过递归，先计算子节点的状态，再回溯推导父节点的状态
4. **无后效性**：由于树的无环性质，子树之间的状态相互独立

## 换根 DP 

树形 DP 中的换根 DP 问题又被称为二次扫描，题目一般需要我们选取一个最优的根，使得结果最优化。

我们一般会先用一次 DFS 去预处理一些z's

### P1364 医院设置

???+ note "题目大意"

    给定一棵有 n 个节点的二叉树，每个节点有一定数量的居民（人口数 w），树中相邻节点之间的距离为 1。现在要在某个节点上建立一家医院，使得所有居民到该医院的总路程（即“人口数 × 到医院的距离”的总和）最小。

    输入包括：
    - 节点总数 n；
    - 每个节点的人口数 w，以及其左子节点 u 和右子节点 v（0 表示无子节点）。

    输出要求：找出一个建医院的位置，使得所有居民到该点的加权距离总和最小，并输出这个最小总距离。
