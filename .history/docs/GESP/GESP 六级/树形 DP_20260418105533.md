# 树形 DP

**树形 DP** 是动态规划的一种特殊形式，专门用于解决**树结构**上的最优化问题。它利用树的递归性质和无环特性，在树上进行状态转移。

## 核心思想

1. **以树为载体**：问题的输入是一个树结构（有根树或无根树）
2. **状态定义**：通常定义 `dp[u][...]` 表示**以结点u为根的子树**在某种约束条件下的最优解
3. **自底向上计算**：通过递归，先计算子结点的状态，再回溯推导父结点的状态
4. **无后效性**：由于树的无环性质，子树之间的状态相互独立

## DP 基础

用数组维护子树信息，然后推导出当前结点的信息。

### B4016 树的直径

???+ note "题目大意"

    给定一棵有 $n$ 个结点的树，求树的直径，即树上最远的两点之间的距离。

考虑一下，假设树根为 1，因为直径是一条最长的链，假设说这条直径经过点 $u$，

那么想一想这条直径会不会被拆成两部分呢：

1. 一部分在 $u$ 的某个子树里，另一部分在另一个子树里？
2. 或者一部分在 $u$ 的某个子树里，另一部分在 $u$ 的上方（即经过它的父亲）？

我们一般会用递归先求子结点的信息，然后再求父亲的信息。所以，我们在处理点 $u$ 的时候，**只能知道它所有子树内部的情况，还不知道“上方”是什么样子**——因为父结点还没处理完，或者根本不会回过头来告诉它。

那怎么办？难道第二种情况（路径穿过 $u$ 并延伸到祖先）就统计不到了吗？

**不用慌！因为那条“穿过 $u$ 并往上走”的路径，一定会在更高层的某个祖先结点那里，被当成“两个子树路径的拼接”而统计到！**

换句话说：**任何一条简单路径，在树中都有唯一的“最高点”（即路径两端点的最近公共祖先，LCA）**。

而我们的 DFS 正好会遍历到这个“最高点”。

试想：假设真正的直径是从结点 $a$ 到结点 $b$，它们的 LCA 是 $p$。

那么从 $p$ 出发，$a$ 一定在某个子树里，$b$ 一定在另一个子树里。

因为直径是最长的路径，所以 $a$ 和 $b$ 是以 $p$ 为根的子树中，最远距离的两点，它们一定是叶子结点。

那么，**从 $p$ 出发，我们只需要找到两个最远的叶子结点，它们的距离就是以 $p$ 为根的最长路径**。

所以，我们只需要在 DFS 中维护两个信息：

- 从当前结点 $u$ 向下走（只进入子树，不回头）所能到达的最远距离，记为 `maxDep[u]`
- 以当前结点 $u$ 为根的子树中，经过 $u$ 的最长路径长度[^1]，记为 `maxDist[u]`

[^1]: 该路径也等同于该子树的最长路径，读者自己思考一下为什么

那么最长路径长度等于最大的两个孩子的 `maxDep[]` 之和，再加上 $2$（$u$ 本身）。

???+ success "参考代码"

    ```cpp linenums="1"
    #include "bits/stdc++.h"
    using namespace std;
    using ll = long long;
    #define endl '\n'
    #define read(x) scanf ("%lld", &x)

    const ll N = 1e6 + 10;
    ll n;
    vector<ll> g[N];

    ll maxDep[N];
    ll maxDist[N];

    void dfs(ll u, ll fa) {
      set<ll> mx; // 利用 mx 求出最远的两个

      for (ll v : g[u]) {
        if (v == fa) continue;
        dfs(v, u); // 先求孩子的信息
        mx.insert(maxDep[v]);
        if (mx.size() > 2) mx.erase(mx.begin()); // 维护两个最大值
      }

      if (mx.size() == 0) {
        maxDep[u] = 0;
        maxDist[u] = 0;
      } else if (mx.size() == 1) {
        maxDep[u] = 1 + *mx.begin();
        maxDist[u] = 1 + *mx.begin();
      } else {
        maxDep[u] = 1 + *(++mx.begin());
        maxDist[u] = 1 + *mx.begin() + *(++mx.begin());
      }
    }

    int main() {
      cin >> n;
      for (ll i = 1; i < n; i++) {
        ll u, v; cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
      }

      dfs(1, 0);

      ll mx = 0;
      for (ll i = 1; i <= n; i++) mx = max(mx, maxDist[i]);
      cout << mx << endl;

      return 0;
    }
    ```

### P1122 最大子树和

???+ note "题目大意"

    给定一棵有 $n$ 个结点的**无根树**（即连通无环图），每个结点有一个“美丽指数”（可为正、负或零）。

    你可以进行任意次“修剪”操作：每次选择一条边将其删除，把树分成两部分，并**丢弃其中一部分**。

    最终目标是通过若干次这样的操作（也可以不操作），**保留一个连通的子树**，使得该子树中所有结点的美丽指数之和**最大**。

    **求这个最大可能的和。**

注意到，我们每一次删除，都会将一棵子树从树中删除掉，什么情况下，要把该子树删掉呢？他的总和为负数的情况下，我们就可以删掉它，因为他对答案是负贡献，尽量选择保留正贡献的子树。

这是一棵无根树，对于树上问题，我们只能先假定一个根（这里假定是1），才能进行DFS搜索。但是最终剩下的子树，却又不一定以 $1$ 为根，但是剩下的这棵树，最终一定会有一个最高点，该最高点一定会将父亲断开。

为了找到这个最高点，我们假设 $u$ 就是该最高点，然后求最大和，因为 $u$ 是最高点了，所以，$u$ 的父亲 $fa$ 一定不会在剩下的子树中，所以，我们只需要求出 $u$ 的最大子树和即可。

最大子树和如何求呢？假设 $x$ 是 $u$ 的儿子，如果以 $x$ 为根的子树能够产生正贡献，就选择保留以 $x$ 为根的子树，否则丢弃；

其他孩子也同理。

???+ success "参考代码"

    ```cpp linenums="1"
    #include "bits/stdc++.h"
    using namespace std;
    using ll = long long;
    #define endl '\n'
    #define read(x) scanf ("%lld", &x)

    const ll N = 1e6 + 10;
    ll n;
    ll a[N];
    vector<ll> g[N];

    ll dp[N];

    void dfs(ll u, ll fa) {
      dp[u] = a[u];
      for (ll v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        dp[u] += max<ll>(0, dp[v]);
      }
    }

    int main() {
      read(n);
      for (ll i = 1; i <= n; i++) read(a[i]);
      for (ll i = 1; i < n; i++) {
        ll u, v; read(u), read(v);
        g[u].push_back(v);
        g[v].push_back(u);
      }

      dfs(1, 0);

      ll mx = -1e18;
      for (ll i = 1; i <= n; i++) mx = max(mx, dp[i]);
      printf("%lld\n", mx);

      return 0;
    }
    ```

### P15801 [GESP202603 六级] 完全二叉树

???+ note "题目大意"

    题目大意总结如下：

    给定一棵有根二叉树（结点编号为 1 到 n，根为 1），每个结点给出其左右子结点编号（若不存在则为 0）。
    要求统计这棵树中**所有以各个结点为根的子树**里，有多少棵是**完全二叉树**。

    > 完全二叉树定义：除最后一层外，其他层都是满的；且最后一层的结点都集中在左侧，不能有“空洞”。

    你需要遍历每个结点作为子树根，判断其对应的子树是否为完全二叉树，并统计满足条件的子树总数。

摆在我们面前的问题是：找出子树是完全二叉树的数量，如果对每一棵子树的暴力判断的话，时间复杂度会爆表！因此，我们得想方设法的复用有效信息。

注意到：

假如 $u$ 的两个孩子分别是 $x$ 和 $y$，如果以 $x$ 为根的子树是满二叉树，以 $y$ 为根的子树是完全二叉树，并且这两棵树的高度一样，那么以 $u$ 为根的子树也是完全二叉树。

确实具备某些递推关系，可以利用孩子的有效信息，推导出父亲的有效信息，避免了暴力判断。

什么情况下，以 $u$ 为根的子树是完全二叉树呢？左右子树又得满足什么特性呢？

1. 左子树是满二叉树，右子树是完全二叉树，并且高度一样。
2. 左子树是完全二叉树，右子树是满二叉树，并且左子树的高度比右子树高 1。

只要满足上述两种情况之一，以 $u$ 为根的子树就是完全二叉树。

如果左右子树都是满二叉树，并且高度一样，那么以 $u$ 为根的子树也是满二叉树。

这里的有效信息是：

1. $u$ 是否是满二叉树。
2. $u$ 是否是完全二叉树。
3. $u$ 这棵子树的高度。

这些都是我们要在 dfs 中记录的信息。

为了方便设计，把空结点也定义成满二叉树、完全二叉树、高度为 0。这样设计的好处是，叶子结点的左右结点都是空结点，空结点是满二叉树、完全二叉树、高度为 0，这样叶子结点就是满二叉树、完全二叉树、高度为 1，符合我们的设计。

并且还有避免很多边界问题。

???+ success "参考代码"

    ```cpp linenums="1"
    #include "bits/stdc++.h"
    using namespace std;
    using ll = long long;
    #define endl '\n'
    #define read(x) scanf ("%lld", &x)

    const ll N = 1e6 + 10;
    ll n, ls[N], rs[N];

    // 是否是满二叉树、是否是完全二叉树
    bool isFull[N], isComplete[N];
    ll dep[N];

    void dfs(ll u) {
      if (u == 0) { // 空结点
        isFull[u] = isComplete[u] = true;
        dep[u] = 0;
        return;
      }

      dfs(ls[u]), dfs(rs[u]);

      // 判断是否是完全二叉树
    if (isFull[ls[u]] && isComplete[rs[u]] && dep[ls[u]] == dep[rs[u]]) isComplete[u] = true;
    if (isComplete[ls[u]] && isFull[rs[u]] && dep[ls[u]] == dep[rs[u]] + 1) isComplete[u] = true;

      // 判断是否是满二叉树
    if (isFull[ls[u]] && isFull[rs[u]] && dep[ls[u]] == dep[rs[u]]) isFull[u] = true;

      dep[u] = max(dep[ls[u]], dep[rs[u]]) + 1;
    }

    int main() {
      read(n);
      for (ll i = 1; i <= n; i++) read(ls[i]), read(rs[i]);
      dfs(1);
      ll cnt = 0;
      for (ll i = 1; i <= n; i++) if (isComplete[i]) cnt++;
      printf("%lld\n", cnt);
      return 0;
    }
    ```

### P1352 没有上司的舞会

???+ note "题目大意"

    给定一棵有 $n$ 个结点的树（代表公司职员的上下级关系，根为校长），每个结点（职员）有一个快乐指数 $r_i$（可正可负）。

    要求选出一部分结点参加舞会，使得 **任意被选中的职员与其直接上司不能同时出席**（即父子结点不能同时选）。

    目标是使所选职员的快乐指数总和最大。

注意到：

如果父亲选了，那么孩子就不能选；如果孩子选了，那么父亲就不能选。

因此，对于每一个结点 $u$，我们有两种选择：

1. $u$ 选，那么 $u$ 的所有孩子都不能选。
2. $u$ 不选，那么 $u$ 的所有孩子都能选。

我们用 $dp[u][0]$ 表示以 $u$ 为根的子树中，**不选 $u$** 的最大快乐值；用 $dp[u][1]$ 表示以 $u$ 为根的子树中，**选 $u$** 的最大快乐值。

如果 $u$ 不选的话，那么对于 $u$ 的每一个孩子来说都可以选或不选，对于孩子的这两种状态来说，保留最大的，所以：

$$
dp[u][0] = \sum_{v \in son(u)} \max(dp[v][0], dp[v][1])
$$

如果 $u$ 选的话，那么对于 $u$ 的每一个孩子来说都不能选，所以：

$$
dp[u][1] = r[u] + \sum_{v \in son(u)} dp[v][0]
$$

???+ success "参考代码"

    ```cpp linenums="1"
    #include "bits/stdc++.h"
    using namespace std;
    using ll = long long;
    #define endl '\n'
    #define read(x) scanf ("%lld", &x)

    const ll N = 1e6 + 10;
    ll n;
    ll r[N];
    vector<ll> g[N];
    ll rd[N], root;
    ll dp[N][2];

    void dfs(ll u, ll p) {
      if (u == 0) return;
      dp[u][0] = 0;
      dp[u][1] = r[u];
      for (ll v : g[u]) {
        if (v == p) continue;
        dfs(v, u);

        dp[u][0] += max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];
      }
    }

    int main() {
      read(n);
      for (ll i = 1; i <= n; i++) read(r[i]);
      for (ll i = 1; i < n; i++) {
        ll l, k; read(l), read(k);
        g[k].push_back(l); rd[l]++;
      }

      // 入度为 0 的点为根
      for (ll i = 1; i <= n; i++) if (rd[i] == 0) root = i;
      dfs(root, 0);

      cout << max(dp[root][0], dp[root][1]) << endl;

      return 0;
    }
    ```

### P2016 [SEERC 2000] 战略游戏

???+ note "题目大意"

    给定一棵有 $n$ 个结点的无根树，你需要在某些结点上放置士兵。
    **一个放在结点上的士兵可以监视（覆盖）与该结点相连的所有边**。

    目标是：**用最少数量的士兵，使得树中的每一条边都被至少一个士兵监视到**。

    请你求出这个最小的士兵数量。

    > 这是一个经典的 **树的最小点覆盖问题**（Vertex Cover on Tree），可以用树形动态规划高效求解。
    > 注意：这里的“覆盖”对象是**边**——每条边必须被其某一端点上的士兵覆盖。

注意到：

对于每一个点来说，就两种状态：**放**与**不放**，并且无论谁作为根都不会影响到最终答案，所以假定 $0$ 为根（这里的结点编号为：$0 \sim n - 1$，所以假定 $0$ 为根）。

题目需要我们求什么？
我们要覆盖的是**所有的边**，而不是所有的点。
动态规划启发口：一般题目问什么，我们就假设一个状态表示什么。

这里假设：

- $dp[i][0]$ 表示**不在结点 $i$ 放士兵**，覆盖以 $i$ 为根的子树中**所有边**所需的最少士兵数；
- $dp[i][1]$ 表示**在结点 $i$ 放士兵**，覆盖以 $i$ 为根的子树中**所有边**所需的最少士兵数。

> 注意：子树中的“所有边”指的是 $i$ 与其子孙之间的那些边，不包括 $i$ 到父结点的边（那条边由父结点的状态来保证覆盖）。

---

分类讨论：

???+ Example "1. 讨论不选 $i$ 的情况"

    如果不在 $i$ 放士兵，那么为了覆盖 $i$ 到每个子结点 $v$ 的边 $(i, v)$，**每一个子结点 $v$ 都必须放士兵**！
    因为如果某个子结点 $v$ 也不放，那么边 $(i, v)$ 就没人覆盖了，这是不允许的。

    所以：

    $$
    dp[i][0] = \sum_{v \in \text{son}(i)} dp[v][1]
    $$

???+ Example "2. 讨论选 $i$ 的情况"

    如果在 $i$ 放士兵，那么 $i$ 与所有子结点之间的边都已经被覆盖了。
    此时每个子结点 $v$ 可以自由选择放或不放，我们取更优的那个方案。

    所以：

    $$
    dp[i][1] = 1 + \sum_{v \in \text{son}(i)} \min(dp[v][0], dp[v][1])
    $$

    > 最后的 `+1` 是因为当前点 $i$ 放了一个士兵。

???+ Example "3. 特殊点讨论：叶子结点"

    对于叶子结点 $i$（除了整棵树只有一个点的情况），它的子树中**没有边**（因为它没有子结点）。

    - 如果不在 $i$ 放士兵（$dp[i][0]$）：子树内无边需要覆盖 → 合法，值为 0。
    - 如果在 $i$ 放士兵（$dp[i][1]$）：放一个士兵 → 值为 1。

    所以：

    $$
    dp[i][0] = 0,\quad dp[i][1] = 1
    $$

---

最终答案

从根结点 $0$ 出发，整棵树的所有边都在其子树内，因此答案为：

$$
\min(dp[0][0],\ dp[0][1])
$$

---

???+ success "参考代码"

    ```cpp linenums="1"
    #include "bits/stdc++.h"
    using namespace std;
    using ll = long long;
    #define endl '\n'
    #define read(x) scanf ("%lld", &x)

    const ll N = 1e6 + 5;
    ll n;
    vector<ll> g[N];
    ll dp[N][2];

    void dfs(ll u, ll fa) {
      dp[u][1] = 1; // u 选，起码会产生 1 个点的贡献
      for (auto v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        dp[u][0] += dp[v][1]; // u 不选，那么孩子 v 必须选才能覆盖 u-v 这条边
        dp[u][1] += min(dp[v][0], dp[v][1]); // u 选，那么孩子 v 可以选也可以不选
      }
    }

    int main() {
      read(n);
      for (ll i = 1; i <= n; i++) {
        ll u; cin >> u;
        ll k; cin >> k;
        for (ll j = 1; j <= k; j++) {
          ll v; cin >> v;
          g[u].push_back(v);
          g[v].push_back(u);
        }
      }

      dfs(0, -1);

      cout << min(dp[0][0], dp[0][1]);

      return 0;
    }
    ```

### P14919 [GESP202512 六级] 路径覆盖

???+ note "题目大意"

    给定一棵 **有根树**（根为结点 1，共 $ n $ 个结点），初始所有结点都是白色。
    你需要选择一些结点染成黑色，使得 **从每个叶子结点到根结点的路径上至少包含一个黑色结点**。
    将结点 $ i $ 染黑需要花费代价 $ c_i $。

    目标：**在满足上述覆盖条件的前提下，使总染色代价最小**。

注意到：

对于每一个点来说，就两种状态：**染**还是**不染**，并且根结点为 $1$，所以我们可以大胆的对点的选取状态进行讨论：

- $dp[i][0]$ 表示**不将结点 $i$ 染色**，以 $i$ 为根的子树中**所有叶子结点到根结点的路径必须经过一个黑点**所需的最少代价；
- $dp[i][1]$ 表示**将结点 $i$ 染色**，覆盖以 $i$ 为根的子树中**所有叶子结点到根结点的路径必须经过一个黑点**所需的最少代价。

---

在递归中，每一个点的信息 $dp[i][0]、dp[i][1]$ 都依赖于子结点的信息，所以我们从叶子结点出发向上递推：

对于叶子结点来说，以叶子结点为根的树中只有它自己，那么它自己必须染色，代价为 $c_i$；所以：

- $dp[i][0] = 1e18$ [^2] 表示这种情况是不合法的；
- $dp[i][1] = c_i$ 表示它自己染色，代价为 $c_i$。

[^2]: 为什么不合法的情况要初始化为 `1e18` 而不是 `-1` 呢？因为下方的答案要选取最小值，那么不合法的情况初始化为无穷大。

叶子结点求出来后，那么叶子结点的祖先结点 $p$ 的状态如何递推出来呢？

- $dp[p][0]$ 表示不将 $p$ 染色，那么以 $p$ 的子结点为根的子树都必须得合法，这样才能保证从叶子结点到 $p$ 的路径上至少包含一个黑色结点，在保证合法的基础上，子结点可选可不选，用 $u$ 来代替 $p$ 的子结点，那么：
    - 如果 $dp[u][0]$ 合法，令 $x = dp[u][0]$；否则不合法的话，令 $x = 1e18$
    - 如果 $dp[u][1]$ 合法，令 $y = dp[u][1]$；否则不合法的话，令 $y = 1e18$
    - 那么 $dp[p][0] = \min(x, y)$

- $dp[p][1]$ 表示将 $p$ 染色，那么 $p$ 的所有子结点都可以不用选了，选了代价就更高了，所以：
    - $dp[p][1] = c[p]$

---

???+ success "参考代码"

    ```cpp linenums="1"
    #include "bits/stdc++.h"
    using namespace std;
    using ll = long long;
    #define endl '\n'
    #define read(x) scanf ("%lld", &x)

    ll n;
    vector<ll> g[1000100];
    ll c[1000100];

    ll dp[1000100][2];

    void dfs(ll u, ll p) {
      dp[u][1] = c[u];
      for (ll v : g[u]) {
        dfs(v, u);
        dp[u][0] += min(dp[v][0], dp[v][1]);
      }
      if (g[u].size() == 0) dp[u][0] = 1e18; // 叶子结点的情况需要特判
    }

    int main() {
      cin >> n;
      for (ll i = 2; i <= n; i++) {
        ll x; cin >> x;
        g[x].push_back(i);
      }
      for (ll i = 1; i <= n; i++) cin >> c[i];
      dfs(1, 0);
      cout << min(dp[1][0], dp[1][1]) << endl;
      return 0;
    }
    ```

### P16294 [蓝桥杯 2026 省 Java A 组] 子树染色

???+ note "题目大意"

    给定一棵 **以结点 1 为根** 的 **n 个结点的树**，以及 **m 个关键结点**。

    对于每个关键结点 $ x $，设其子树大小为 $ s $（包括 $ x $ 自身及其所有后代），则要求：  
    > **在该子树中，至少有 $ \lceil \frac{s}{2} \rceil $ 个结点被染色**。

    目标是：  
    ✅ **满足所有关键结点的染色下限要求的前提下，使整棵树中被染色的结点总数最少**。

    你需要输出这个 **最小染色数量**。

注意到：

如果当前点是关键结点，那么必须得满足它的下限需求；  
但如果当前点不是关键点的话，为了让染色的总数尽可能少，那么就尽量不对它进行处理，不要增加多余的染色点。

染色具有“向上贡献”效应：一个结点被染色，会同时计入其所有祖先关键结点的子树染色计数中。  
如果对于点 $u$ 来说，如果它是关键结点，并且它的后代结点 $v$ 也是关键结点，我们应该先满足 $v$ 的下限需求，这样对于 $u$ 来说就已经有部分黑点了，可以节省染色的个数。

---

假定 $dp[i]$ 表示以 $i$ 为根的子树中，在满足该子树中所有关键点需求的前提下的最少染色数，那么分类讨论：

- 如果 $i$ 不是关键结点，那么 $dp[i] = \sum_{v \in \text{son}(i)} dp[v]$；
- 如果 $i$ 是关键结点，在满足所有关键子结点的情况下，最起码需要的染色数是：$t = \sum_{v \in \text{son}(i)} dp[v]$，  
  若这个最起码的要求 $t$ 已经 $\geq \lceil \frac{siz[i]}{2} \rceil$，那么 $dp[u] = t$；  
  否则就需要把空白点染色，染到刚刚好够 $\geq \lceil \frac{siz[i]}{2} \rceil$ 为止，此时 $dp[u] = \lceil \frac{siz[i]}{2} \rceil$。

---

???+ success "参考代码"

    ```cpp linenums="1"
    #include "bits/stdc++.h"
    using namespace std;
    using ll = long long;
    #define endl '\n'
    #define read(x) scanf ("%lld", &x)

    ll n, m;
    ll sp[1000100];
    vector<ll> g[1000100];

    ll dp[1000100];
    ll siz[1000100];

    void dfs(ll u, ll p) {
      siz[u] = 1;
      for (auto v : g[u]) {
        if (v == p) continue;
        dfs(v, u);
        siz[u] += siz[v];
        dp[u] += dp[v];
      }
      if (sp[u] && dp[u] < (ll)ceil(siz[u] / 2.0)) dp[u] = (ll)ceil(siz[u] / 2.0);
    }

    int main()
    {
      read(n), read(m);
      for (ll i = 1; i <= m; i++) {
        ll x; read(x); sp[x] = 1;
      }
      for (ll i = 1; i < n; i++) {
        ll u, v; read(u), read(v);
        g[u].push_back(v);
        g[v].push_back(u);
      }

      dfs(1, 0);

      cout << dp[1] << endl;

      return 0;
    }
    ```

### P10723 [GESP202406 七级] 黑白翻转

???+ note "题目大意"

    给定一棵 **n 个节点的树**，每个节点初始为 **黑色（1）或白色（0）**。   
    定义一棵“**美丽树**”：**删除所有白色节点后，剩下的黑色节点仍然构成一棵树**（即连通且无环）。

    你可以进行操作：**将任意一个白色节点变为黑色**。   
    问：**最少需要多少次操作**，才能让原树变成美丽树？  

注意到：

白色结点是需要删除的，并且可以选择某些白点改为黑点，题目没有说黑点可以改成白点，也就是说，原有的黑点是必须要保留下来的。  
我们想象一下，如果把白点都直接删除的，遗留下来的黑点不一定能够连通，如果能够连通的话，就刚刚好是一棵树，满足题目的要求；不连通的话得想办法加一些

## 换根 DP 

树形 DP 中的换根 DP 问题又被称为二次扫描，题目一般需要我们选取一个最优的根，使得结果最优化。

我们一般会先假定 1 为根，然后用一次 DFS 去预处理一些子树的信息，然后再用第二次 DFS 将父亲的信息传达给孩子，求出以该孩子为根时的信息。

### P1364 医院设置

???+ note "题目大意"

    给定一棵有 $n$ 个结点的二叉树，每个结点有一定数量的居民（人口数 $w$），树中相邻结点之间的距离为 1。
  
    现在要在某个结点上建立一家医院，使得所有居民到该医院的总路程（即“人口数 × 到医院的距离”的总和）最小。

    输入包括：

    - 结点总数 $n$；
    - 每个结点的人口数 $w$，以及其左子结点 $u$ 和右子结点 $v$（0 表示无子结点）。

    输出要求：找出一个建医院的位置，使得所有居民到该点的加权距离总和最小，并输出这个最小总距离。

我们面对的问题是：在一棵二叉树上选择一个点建立医院，使得所有居民走到该点的**总路程最小**。每个点有一定数量的居民，相邻结点距离为 1。

目标是快速求出：**以任意结点 $u$ 为医院时，整棵树所有居民到 $u$ 的总距离**。

#### 第一步：固定根（比如 1 号点），预处理子树信息

我们先假设医院建在 1 号点，用 `dfs1` 自底向上计算两个关键数组：

- `siz[u]`：表示以 $u$ 为根的子树中，**总共有多少居民**（包括 $u$ 结点自己）。
- `dp[u]`：表示在 $u$ 的子树内部，所有居民走到 $u$ 的**总路程**。

怎么算？

对于结点 $u$，它的左孩子是 `ls[u]`，右孩子是 `rs[u]`。

左子树中每个人走到 $u$，都要先走到左孩子 `ls[u]`（产生的路程总和是 `dp[ls[u]]`），再走一步到 $u$（共 `siz[ls[u]]` 人再多走一步从左孩子到达 $u$，多走 `siz[ls[u]]` 路程）。

右子树同理。

所以：

```cpp
dp[u] = dp[ls[u]] + siz[ls[u]] + dp[rs[u]] + siz[rs[u]];
siz[u] = siz[ls[u]] + siz[rs[u]] + w[u];
```

用 dfs1 预处理信息：

```cpp linenums="1"
void dfs1(ll u) {
  if (u == 0) return;

  dfs1(ls[u]);
  dfs1(rs[u]);

  dp[u] = dp[ls[u]] + siz[ls[u]] + dp[rs[u]] + siz[rs[u]];
  siz[u] = siz[ls[u]] + siz[rs[u]] + w[u];
}
```

那么现在 $1 \sim n$ 这些点中，只有 $1$ 号点的 $dp[1]$ 是真的能够表示成所有居民到达 $1$ 的路程总和，其他点(假定为$u$)的 $dp[u]$ 都只能表示为子树中的所有居民到达 $u$ 的路程总和，还缺少 $siz[1] - siz[u]$ 人没有走到 $u$。

---

#### 第二步：换根！从父结点推导子结点的答案

现在问题来了：如果我们把医院从父结点 `fa` 换到它的孩子 `u`，总路程会怎么变？

关键观察：

- 原来在 `u` 子树里的 `siz[u]` 个居民，**每人少走 1 步**（因为医院靠近他们了）。
- 其余 `siz[1] - siz[u]` 个居民（不在 `u` 子树里），**每人多走 1 步**（因为医院远离他们了）。

所以，总路程的变化量是：

$$
\Delta = -(siz[u]) + (siz[1] - siz[u]) = siz[1] - 2 \cdot siz[u]
$$

于是我们得到换根公式：

$$
dp[u] = dp[fa] + siz[1] - 2 \cdot siz[u]
$$

用 dfs2 完成换根递推：

```cpp linenums="1"
void dfs2(ll u, ll fa) {
  if (u == 0) return;
  if (fa != 0) {
    dp[u] = dp[fa] + siz[1] - 2 * siz[u];
  }

  dfs2(ls[u], u);
  dfs2(rs[u], u);
}
```

#### 第三步：找到最优的根，使得答案最优

时间复杂度：$O(n)$

???+ success "参考代码"

    ```cpp linenums="1"
    #include "bits/stdc++.h"
    using namespace std;
    using ll = long long;
    #define endl '\n'
    #define read(x) scanf ("%lld", &x)

    const ll N = 1e6 + 10;
    ll n;
    ll w[N], ls[N], rs[N];

    ll siz[N]; 
    ll dp[N]; 

    void dfs1(ll u) {
      if (u == 0) return;

      dfs1(ls[u]);
      dfs1(rs[u]);

      dp[u] = dp[ls[u]] + siz[ls[u]] + dp[rs[u]] + siz[rs[u]];
      siz[u] = siz[ls[u]] + siz[rs[u]] + w[u];
    }

    void dfs2(ll u, ll fa) {
      if (u == 0) return;
      if (fa != 0) {
        dp[u] = dp[fa] + siz[1] - 2 * siz[u];
      }

      dfs2(ls[u], u);
      dfs2(rs[u], u);
    }

    int main() {
      cin >> n;
      for (ll i = 1; i <= n; i++) read(w[i]), read(ls[i]), read(rs[i]);
      dfs1(1);
      dfs2(1, 0);

      ll ans = 1e18;
      for (ll i = 1; i <= n; i++) ans = min(ans, dp[i]);
      cout << ans << endl;
      return 0;
    }
    ```
