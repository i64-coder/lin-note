# 树形 DP

**树形 DP** 是动态规划的一种特殊形式，专门用于解决**树结构**上的最优化问题。它利用树的递归性质和无环特性，在树上进行状态转移。

## 核心思想

1. **以树为载体**：问题的输入是一个树结构（有根树或无根树）
2. **状态定义**：通常定义 `dp[u][...]` 表示**以节点u为根的子树**在某种约束条件下的最优解
3. **自底向上计算**：通过递归，先计算子节点的状态，再回溯推导父节点的状态
4. **无后效性**：由于树的无环性质，子树之间的状态相互独立

## 换根 DP 

树形 DP 中的换根 DP 问题又被称为二次扫描，题目一般需要我们选取一个最优的根，使得结果最优化。

我们一般会先假定 1 为根，然后用一次 DFS 去预处理一些子树的信息，然后再用第二次 DFS 将父亲的信息传达给孩子，求出以该孩子为根时的信息。

### P1364 医院设置

???+ note "题目大意"

    给定一棵有 n 个节点的二叉树，每个节点有一定数量的居民（人口数 w），树中相邻节点之间的距离为 1。
    
    现在要在某个节点上建立一家医院，使得所有居民到该医院的总路程（即“人口数 × 到医院的距离”的总和）最小。

    输入包括：

    - 节点总数 n；
    - 每个节点的人口数 w，以及其左子节点 u 和右子节点 v（0 表示无子节点）。

    输出要求：找出一个建医院的位置，使得所有居民到该点的加权距离总和最小，并输出这个最小总距离。

我们面对的问题是：在一棵二叉树上选择一个点建立医院，使得所有居民走到该点的**总路程最小**。每个点有一定数量的居民，相邻节点距离为 1。

目标是快速求出：**以任意节点 $u$ 为医院时，整棵树所有居民到 $u$ 的总距离**。

#### 第一步：固定根（比如 1 号点），预处理子树信息

我们先假设医院建在 1 号点，用 `dfs1` 自底向上计算两个关键数组：

- `siz[u]`：表示以 $u$ 为根的子树中，**总共有多少居民**（包括 $u$ 节点自己）。
- `dp[u]`：表示在 $u$ 的子树内部，所有居民走到 $u$ 的**总路程**。

怎么算？

对于节点 $u$，它的左孩子是 `ls[u]`，右孩子是 `rs[u]`。  

左子树中每个人走到 $u$，都要先走到左孩子 `ls[u]`（产生的路程总和是 `dp[ls[u]]`），再走一步到 $u$（共 `siz[ls[u]]` 人再多走一步从左孩子到达 $u$，多走 `siz[ls[u]]` 路程）。  

右子树同理。

所以：

```cpp
dp[u] = dp[ls[u]] + siz[ls[u]] + dp[rs[u]] + siz[rs[u]];
siz[u] = siz[ls[u]] + siz[rs[u]] + w[u];
```

用 dfs1 预处理信息：

```cpp linenums="1"
void dfs1(ll u) {
  if (u == 0) return;

  dfs1(ls[u]);
  dfs1(rs[u]);

  dp[u] = dp[ls[u]] + siz[ls[u]] + dp[rs[u]] + siz[rs[u]];
  siz[u] = siz[ls[u]] + siz[rs[u]] + w[u];
}
```

那么现在 $1 \sim n$ 这些点中，只有 $1$ 号点的 $dp[1]$ 是真的能够表示成所有居民到达 $1$ 的路程总和，其他点(假定为$u$)的 $dp[u]$ 都只能表示为子树中的所有居民到达 $u$ 的路程总和，还缺少 $siz[1] - siz[u]$ 人没有走到 $u$。

---

#### 第二步：换根！从父节点推导子节点的答案

现在问题来了：如果我们把医院从父节点 `fa` 换到它的孩子 `u`，总路程会怎么变？

关键观察：  

- 原来在 `u` 子树里的 `siz[u]` 个居民，**每人少走 1 步**（因为医院靠近他们了）。
- 其余 `siz[1] - siz[u]` 个居民（不在 `u` 子树里），**每人多走 1 步**（因为医院远离他们了）。

所以，总路程的变化量是：

$$
\Delta = -(siz[u]) + (siz[1] - siz[u]) = siz[1] - 2 \cdot siz[u]
$$

于是我们得到换根公式：

$$
dp[u] = dp[fa] + siz[1] - 2 \cdot siz[u]
$$

用 dfs2 完成换根递推：

```cpp linenums="1"
void dfs2(ll u, ll fa) {
  if (u == 0) return;
  if (fa != 0) {
    dp[u] = dp[fa] - 2 * siz[u];
  }

  dfs2(ls[u], u);
  dfs2(rs[u], u);
}
```
