# 指针

## 指针的概念

在 C++ 中，变量、数组、结构体等用于存储数据，它们本质上是内存中的一块区域，就像一个个“容器”。   
每一个变量都有一个内存地址，只要知道该地址，我就可以修改该变量内存储的值。  
C++ 提供了指针，指针专门存储内存地址，然后我们就可以通过指针篡改该变量的值。

## 获取地址

C++ 中通过取地址符 `&` 获取变量的地址，例如：

### 获取变量的地址

例一：

```cpp linenums="1"
int x = 10;
cout << &x << '\n'; // 输出变量 x 的地址
```

例二：

```cpp linenums="1"
double x = 10.0;
cout << &x << '\n'; // 输出变量 x 的地址
```

例三：

```cpp linenums="1"
struct Node { int x, y; };

Node node = { 1, 2 };
cout << &node << '\n'; // 输出结构体变量的地址
```

例四：

```cpp linenums="1"
int a[10] = {0, 1, 2, 3};
cout << &a[0] << '\n'; // 输出下标 0 的地址
cout << &a[1] << '\n'; // 输出下标 1 的地址
cout << &a[2] << '\n'; // 输出下标 2 的地址
```

### 获取数组的首元素地址

数组名其实就是数组首元素的地址，运行下方代码，就会发现输出的内容都一样：

```cpp linenums="1"
int a[10] = {0, 1, 2, 3};

cout << a << '\n';     // 输出数组首元素的地址
cout << &a[0] << '\n'; // 输出数组首元素的地址
```

其他下标的地址，可以通过数组名加上偏移量来计算：

```cpp linenums="1"
int a[10] = {0, 1, 2, 3};

// 输出数组首元素的地址
cout << &a[0] << '\n'; 
cout << a << '\n';

// 输出数组下标 1 的地址
cout << &a[1] << '\n';
cout << a + 1 << '\n';

// 输出数组下标 2 的地址
cout << &a[2] << '\n';
cout << a + 2 << '\n';

// 输出数组下标 3 的地址
cout << &a[3] << '\n';
cout << a + 3 << '\n';
```
