# 指针

## 指针的概念

在 C++ 中，变量、数组、结构体等用于存储数据，它们本质上是内存中的一块区域，就像一个个“容器”。   
而指针是一种特殊类型的变量，它不直接存储数据本身，而是存储另一个变量在内存中的地址。

![alt text](assets/image.png)

如何获取变量的地址呢？  
在 C++ 中，可以使用取地址运算符 `&` 来获取变量的地址。例如：

```cpp
int x = 10;
cout << &x; // 输出 x 的地址
```

## 指针的声明和初始化

声明指针时，需要在变量名前加上 `*`，表示这是一个指针变量。例如：

```cpp
int *p; // 声明一个指向 int 类型的指针变量 p
```

初始化指针时，需要将一个变量的地址赋值给它。例如：

```cpp
int x = 10;
int *p = &x; // 将 x 的地址赋值给指针变量 p

// 下面都可以输出 x 的地址
cout << &x << '\n';
cout << p << '\n';
```

## 指针的解引用

什么是解引用呢？  
解引用是指通过指针获取它所指向的变量。在 C++ 中，可以使用 `*` 运算符来解引用指针。例如：

```cpp
int x = 10;
int *p = &x;
cout << *p; // 输出 x 的值，即 10
```
