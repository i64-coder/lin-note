Zensical¶

1. 提示块¶

1. 基础语法¶

Note

这是一个普通提示块。

对应的 markdown 代码： 

!!! note

    这是一个普通提示块。

2. 自定义标题¶

高效技巧

使用 Ctrl+Shift+P 打开命令面板。

对应的 markdown 代码： 

!!! tip "高效技巧"

    使用 `Ctrl+Shift+P` 打开命令面板。

3. 隐藏标题¶

操作不可逆！

对应的 markdown 代码： 

!!! danger ""

    操作不可逆！

4. 可折叠块¶

Question

点击展开常见问题。

对应的 markdown 代码： 

??? question

    点击展开常见问题。

默认展开¶

已完成

构建成功，无错误。

对应的 markdown 代码： 

???+ success "已完成"

    构建成功，无错误。

5. 内联提示（侧边浮动）¶

说明

此为右浮动提示块。

对应的 markdown 代码： 

!!! info inline end "说明"

    此为右浮动提示块。

⚠️ 必须写在目标段落之前，窄屏自动转为块级。

6. 嵌套提示块¶

外层

外层内容。

内层

内层警告。

对应的 markdown 代码： 

!!! note "外层"

    外层内容。

    !!! warning "内层"

        内层警告。
