树形 DP¶

树形 DP 是动态规划的一种特殊形式，专门用于解决树结构上的最优化问题。它利用树的递归性质和无环特性，在树上进行状态转移。

核心思想¶

  1. 以树为载体：问题的输入是一个树结构（有根树或无根树）
  2. 状态定义：通常定义 dp[u][...] 表示以节点u为根的子树在某种约束条件下的最优解
  3. 自底向上计算：通过递归，先计算子节点的状态，再回溯推导父节点的状态
  4. 无后效性：由于树的无环性质，子树之间的状态相互独立

DP 基础¶

用数组维护子树信息，然后推导出当前节点的信息。

B4016 树的直径¶

题目大意

给定一棵有 \(n\) 个节点的树，求树的直径，即树上最远的两点之间的距离。

考虑一下，假设树根为 1，因为直径是一条最长的链，假设说这条直径经过点 \(u\)，

那么想一想这条直径会不会被拆成两部分呢：

  1. 一部分在 \(u\) 的某个子树里，另一部分在另一个子树里？
  2. 或者一部分在 \(u\) 的某个子树里，另一部分在 \(u\) 的上方（即经过它的父亲）？

我们一般会用递归先求子节点的信息，然后再求父亲的信息。所以，我们在处理点 \(u\) 的时候，只能知道它所有子树内部的情况，还不知道“上方”是什么样子——因为父节点还没处理完，或者根本不会回过头来告诉它。

那怎么办？难道第二种情况（路径穿过 \(u\) 并延伸到祖先）就统计不到了吗？

不用慌！因为那条“穿过 \(u\) 并往上走”的路径，一定会在更高层的某个祖先节点那里，被当成“两个子树路径的拼接”而统计到！

换句话说：任何一条简单路径，在树中都有唯一的“最高点”（即路径两端点的最近公共祖先，LCA）。

而我们的 DFS 正好会遍历到这个“最高点”。

试想：假设真正的直径是从节点 \(a\) 到节点 \(b\)，它们的 LCA 是 \(p\)。

那么从 \(p\) 出发，\(a\) 一定在某个子树里，\(b\) 一定在另一个子树里。

因为直径是最长的路径，所以 \(a\) 和 \(b\) 是以 \(p\) 为根的子树中，最远距离的两点，它们一定是叶子节点。

那么，从 \(p\) 出发，我们只需要找到两个最远的叶子节点，它们的距离就是以 \(p\) 为根的最长路径。

所以，我们只需要在 DFS 中维护两个信息：

  • 从当前节点 \(u\) 向下走（只进入子树，不回头）所能到达的最远距离，记为 maxDep[u]
  • 以当前节点 \(u\) 为根的子树中，经过 \(u\) 的最长路径长度1，记为 maxDist[u]

那么最长路径长度等于最大的两个孩子的 maxDep[] 之和，再加上 \(2\)（\(u\) 本身）。

#include "bits/stdc++.h"
using namespace std;
using ll = long long;
#define endl '\n'
#define read(x) scanf ("%lld", &x)

const ll N = 1e6 + 10;
ll n;
vector<ll> g[N];

ll maxDep[N];
ll maxDist[N];

void dfs(ll u, ll fa) {
  set<ll> mx; // 利用 mx 求出最远的两个

  for (ll v : g[u]) {
    if (v == fa) continue;
    dfs(v, u); // 先求孩子的信息
    mx.insert(maxDep[v]);
    if (mx.size() > 2) mx.erase(mx.begin()); // 维护两个最大值
  }

  if (mx.size() == 0) {
    maxDep[u] = 0;
    maxDist[u] = 0;
  }
  else if (mx.size() == 1) {
    maxDep[u] = 1 + *mx.begin();
    maxDist[u] = 1 + *mx.begin();
  }
  else {
    maxDep[u] = 1 + *(++mx.begin());
    maxDist[u] = 1 + *mx.begin() + *(++mx.begin());
  }
}

int main()
{
  cin >> n;
  for (ll i = 1; i < n; i ++) {
    ll u, v; cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u);
  }

  dfs(1, 0);

  ll mx = 0;
  for (ll i = 1; i <= n; i ++) mx = max(mx, maxDist[i]);
  cout << mx << endl;

  return 0;
}

P1122 最大子树和¶

题目大意

给定一棵有 \(n\) 个节点的无根树（即连通无环图），每个节点有一个“美丽指数”（可为正、负或零）。

你可以进行任意次“修剪”操作：每次选择一条边将其删除，把树分成两部分，并丢弃其中一部分。

最终目标是通过若干次这样的操作（也可以不操作），保留一个连通的子树，使得该子树中所有节点的美丽指数之和最大。

求这个最大可能的和。

注意到，我们每一次删除，都会将一棵子树从树中删除掉，什么情况下，要把该子树删掉呢？他的总和为负数的情况下，我们就可以删掉它，因为他对答案是负贡献，尽量选择保留正贡献的子树。

这是一棵无根树，对于树上问题，我们只能先假定一个根（这里假定是1），才能进行DFS搜索。但是最终剩下的子树，却又不一定以 \(1\) 为根，但是剩下的这棵树，最终一定会有一个最高点，该最高点一定会将父亲断开。

为了找到这个最高点，我们假设 \(u\) 就是该最高点，然后求最大和，因为 \(u\) 是最高点了，所以，\(u\) 的父亲 \(fa\) 一定不会在剩下的子树中，所以，我们只需要求出 \(u\) 的最大子树和即可。

最大子树和如何求呢？假设 \(x\) 是 \(u\) 的儿子，如果以 \(x\) 为根的子树能够产生正贡献，就选择保留以 \(x\) 为根的子树，否则丢弃；

其他孩子也同理。

#include "bits/stdc++.h"
using namespace std;
using ll = long long;
#define endl '\n'
#define read(x) scanf ("%lld", &x)

const ll N = 1e6 + 10;
ll n;
ll a[N];
vector<ll> g[N];

ll dp[N];

void dfs(ll u, ll fa) {
  dp[u] = a[u];
  for (ll v : g[u]) {
    if (v == fa) continue;
    dfs(v, u);
    dp[u] += max<ll>(0, dp[v]);
  }
}

int main()
{
  read(n);
  for (ll i = 1; i <= n; i++) read(a[i]);
  for (ll i = 1; i < n; i++) {
    ll u, v; read(u), read(v);
    g[u].push_back(v);
    g[v].push_back(u);
  }

  dfs(1, 0);

  ll mx = -1e18;
  for (ll i = 1; i <= n; i++) mx = max(mx, dp[i]);
  printf("%lld\n", mx);

  return 0;
}

P15801 [GESP202603 六级] 完全二叉树¶

题目大意

题目大意总结如下：

给定一棵有根二叉树（节点编号为 1 到 n，根为 1），每个节点给出其左右子节点编号（若不存在则为 0）。 要求统计这棵树中所有以各个节点为根的子树里，有多少棵是完全二叉树。

完全二叉树定义：除最后一层外，其他层都是满的；且最后一层的节点都集中在左侧，不能有“空洞”。

你需要遍历每个节点作为子树根，判断其对应的子树是否为完全二叉树，并统计满足条件的子树总数。

摆在我们面前的问题是：找出子树是完全二叉树的数量，如果对每一棵子树的暴力判断的话，时间复杂度会爆表！因此，我们得想方设法的复用有效信息。

注意到：

假如 \(u\) 的两个孩子分别是 \(x\) 和 \(y\)，如果以 \(x\) 为根的子树是满二叉树，以 \(y\) 为根的子树是完全二叉树，并且这两棵树的高度一样，那么以 \(u\) 为根的子树也是完全二叉树。

确实具备某些递推关系，可以利用孩子的有效信息，推导出父亲的有效信息，避免了暴力判断。

什么情况下，以 \(u\) 为根的子树是完全二叉树呢？左右子树又得满足什么特性呢？

  1. 左子树是满二叉树，右子树是完全二叉树，并且高度一样。
  2. 左子树是完全二叉树，右子树是满二叉树，并且左子树的高度比右子树高 1。

只要满足上述两种情况之一，以 \(u\) 为根的子树就是完全二叉树。

如果左右子树都是满二叉树，并且高度一样，那么以 \(u\) 为根的子树也是满二叉树。

这里的有效信息是：

  1. \(u\) 是否是满二叉树。
  2. \(u\) 是否是完全二叉树。
  3. \(u\) 这棵子树的高度。

这些都是我们要在 dfs 中记录的信息。

为了方便设计，把空节点也定义成满二叉树、完全二叉树、高度为 0。这样设计的好处是，叶子节点的左右节点都是空节点，空节点是满二叉树、完全二叉树、高度为 0，这样叶子节点就是满二叉树、完全二叉树、高度为 1，符合我们的设计。

并且还有避免很多边界问题。

#include "bits/stdc++.h"
using namespace std;
using ll = long long;
#define endl '\n'
#define read(x) scanf ("%lld", &x)

const ll N = 1e6 + 10;
ll n, ls[N], rs[N];

// 是否是满二叉树、是否是完全二叉树
bool isFull[N], isComplete[N];
ll dep[N];

void dfs(ll u) {
  if (u == 0) { // 空节点
    isFull[u] = isComplete[u] = true;
    dep[u] = 0;
    return;
  }

  dfs(ls[u]), dfs(rs[u]);

  // 判断是否是完全二叉树
  if (isFull[ls[u]] && isComplete[rs[u]] && dep[ls[u]] == dep[rs[u]]) isComplete[u] = true;
  if (isComplete[ls[u]] && isFull[rs[u]] && dep[ls[u]] == dep[rs[u]] + 1) isComplete[u] = true;

  // 判断是否是满二叉树
  if (isFull[ls[u]] && isFull[rs[u]] && dep[ls[u]] == dep[rs[u]]) isFull[u] = true;

  dep[u] = max(dep[ls[u]], dep[rs[u]]) + 1;
}

int main()
{
  read(n);
  for (ll i = 1; i <= n; i++) read(ls[i]), read(rs[i]);
  dfs(1);
  ll cnt = 0;
  for (ll i = 1; i <= n; i ++) if (isComplete[i]) cnt ++;
  printf ("%lld\n", cnt);
  return 0;
}

P1352 没有上司的舞会¶

题目大意

给定一棵有 \(n\) 个节点的树（代表公司职员的上下级关系，根为校长），每个节点（职员）有一个快乐指数 \(r_i\)（可正可负）。

要求选出一部分节点参加舞会，使得 任意被选中的职员与其直接上司不能同时出席（即父子节点不能同时选）。

目标是使所选职员的快乐指数总和最大。

注意到：

如果父亲选了，那么孩子就不能选；如果孩子选了，那么父亲就不能选。

因此，对于每一个节点 \(u\)，我们有两种选择：

  1. \(u\) 选，那么 \(u\) 的所有孩子都不能选。
  2. \(u\) 不选，那么 \(u\) 的所有孩子都能选。

我们用 \(dp[u][0]\) 表示以 \(u\) 为根的子树中，不选 \(u\) 的最大快乐值；用 \(dp[u][1]\) 表示以 \(u\) 为根的子树中，选 \(u\) 的最大快乐值。

如果 \(u\) 不选的话，那么对于 \(u\) 的每一个孩子来说都可以选或不选，对于孩子的这两种状态来说，保留最大的，所以：

\[ dp[u][0] = \sum_{v \in son(u)} \max(dp[v][0], dp[v][1]) \]

如果 \(u\) 选的话，那么对于 \(u\) 的每一个孩子来说都不能选，所以：

\[ dp[u][1] = r[u] + \sum_{v \in son(u)} dp[v][0] \]

#include "bits/stdc++.h"
using namespace std;
using ll = long long;
#define endl '\n'
#define read(x) scanf ("%lld", &x)

const ll N = 1e6 + 10;
ll n;
ll r[N];
vector<ll> g[N];
ll rd[N], root;
ll dp[N][2];

void dfs(ll u, ll p) {
  if (u == 0) return;
  dp[u][0] = 0;
  dp[u][1] = r[u];
  for (ll v : g[u]) {
    if (v == p) continue;
    dfs(v, u);

    dp[u][0] += max(dp[v][0], dp[v][1]);
    dp[u][1] += dp[v][0];
  }
}

int main()
{
  read(n);
  for (ll i = 1; i <= n; i++) read(r[i]);
  for (ll i = 1; i < n; i++) {
    ll l, k; read(l), read(k);
    g[k].push_back(l); rd[l] ++;
  }

  // 入度为 0 的点为根
  for (ll i = 1; i <= n; i ++) if (rd[i] == 0) root = i;
  dfs(root, 0);

  cout << max(dp[root][0], dp[root][1]) << endl;

  return 0;
}

换根 DP¶

树形 DP 中的换根 DP 问题又被称为二次扫描，题目一般需要我们选取一个最优的根，使得结果最优化。

我们一般会先假定 1 为根，然后用一次 DFS 去预处理一些子树的信息，然后再用第二次 DFS 将父亲的信息传达给孩子，求出以该孩子为根时的信息。

P1364 医院设置¶

题目大意

给定一棵有 \(n\) 个节点的二叉树，每个节点有一定数量的居民（人口数 \(w\)），树中相邻节点之间的距离为 1。

现在要在某个节点上建立一家医院，使得所有居民到该医院的总路程（即“人口数 × 到医院的距离”的总和）最小。

输入包括：

  • 节点总数 \(n\)；
  • 每个节点的人口数 \(w\)，以及其左子节点 \(u\) 和右子节点 \(v\)（0 表示无子节点）。

输出要求：找出一个建医院的位置，使得所有居民到该点的加权距离总和最小，并输出这个最小总距离。

我们面对的问题是：在一棵二叉树上选择一个点建立医院，使得所有居民走到该点的总路程最小。每个点有一定数量的居民，相邻节点距离为 1。

目标是快速求出：以任意节点 \(u\) 为医院时，整棵树所有居民到 \(u\) 的总距离。

第一步：固定根（比如 1 号点），预处理子树信息¶

我们先假设医院建在 1 号点，用 dfs1 自底向上计算两个关键数组：

  • siz[u]：表示以 \(u\) 为根的子树中，总共有多少居民（包括 \(u\) 节点自己）。
  • dp[u]：表示在 \(u\) 的子树内部，所有居民走到 \(u\) 的总路程。

怎么算？

对于节点 \(u\)，它的左孩子是 ls[u]，右孩子是 rs[u]。

左子树中每个人走到 \(u\)，都要先走到左孩子 ls[u]（产生的路程总和是 dp[ls[u]]），再走一步到 \(u\)（共 siz[ls[u]] 人再多走一步从左孩子到达 \(u\)，多走 siz[ls[u]] 路程）。

右子树同理。

所以：

dp[u] = dp[ls[u]] + siz[ls[u]] + dp[rs[u]] + siz[rs[u]];
siz[u] = siz[ls[u]] + siz[rs[u]] + w[u];

那么现在 \(1 \sim n\) 这些点中，只有 \(1\) 号点的 \(dp[1]\) 是真的能够表示成所有居民到达 \(1\) 的路程总和，其他点(假定为\(u\))的 \(dp[u]\) 都只能表示为子树中的所有居民到达 \(u\) 的路程总和，还缺少 \(siz[1] - siz[u]\) 人没有走到 \(u\)。

第二步：换根！从父节点推导子节点的答案¶

现在问题来了：如果我们把医院从父节点 fa 换到它的孩子 u，总路程会怎么变？

关键观察：

  • 原来在 u 子树里的 siz[u] 个居民，每人少走 1 步（因为医院靠近他们了）。
  • 其余 siz[1] - siz[u] 个居民（不在 u 子树里），每人多走 1 步（因为医院远离他们了）。

所以，总路程的变化量是：

\[ \Delta = -(siz[u]) + (siz[1] - siz[u]) = siz[1] - 2 \cdot siz[u] \]

于是我们得到换根公式：

\[ dp[u] = dp[fa] + siz[1] - 2 \cdot siz[u] \]

用 dfs2 完成换根递推：

  if (fa != 0) {
    dp[u] = dp[fa] + siz[1] - 2 * siz[u];
  }

  dfs2(ls[u], u);
  dfs2(rs[u], u);
}

#include "bits/stdc++.h"
using namespace std;
using ll = long long;
#define endl '\n'
#define read(x) scanf ("%lld", &x)

const ll N = 1e6 + 10;
ll n;
ll w[N], ls[N], rs[N];

ll siz[N]; 
ll dp[N]; 

void dfs1(ll u) {
  if (u == 0) return;

  dfs1(ls[u]);
  dfs1(rs[u]);

  dp[u] = dp[ls[u]] + siz[ls[u]] + dp[rs[u]] + siz[rs[u]];
  siz[u] = siz[ls[u]] + siz[rs[u]] + w[u];
}

void dfs2(ll u, ll fa) {
  if (u == 0) return;
  if (fa != 0) {
    dp[u] = dp[fa] + siz[1] - 2 * siz[u];
  }

  dfs2(ls[u], u);
  dfs2(rs[u], u);
}

int main()
{
  cin >> n;
  for (ll i = 1; i <= n; i ++) read(w[i]), read(ls[i]), read(rs[i]);
  dfs1(1);
  dfs2(1, 0);

  ll ans = 1e18;
  for (ll i = 1; i <= n; i ++) ans = min(ans, dp[i]);
  cout << ans << endl;
  return 0;
}
